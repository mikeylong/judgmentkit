# First real builder encounter

Observe one builder's recent interface task before committing to the nine-episode pilot. This document is a blank facilitator guide. No participant or result has been recorded.

1. Ask the builder to show a recent task where their agent needed repeated correction. Record the original intent, who uses the interface, what that person needs to accomplish, the source files, and what the builder corrected. Keep the builder's own account distinct from your observation.
2. Agree on a result the builder would accept and a task an eventual user can attempt. Record the builder's tolerable extra setup and review time. Use a task they can work on with the supplied sources and without changing production data.
3. Compare the normal agent workflow with JudgmentKit on matched tasks. Record task differences, order, and prior experience. One builder repeating the same brief introduces learning effects. Explain that limitation if a matched second task is unavailable.
4. Observe from setup through repairs and handoff. Record changes the builder makes to JudgmentKit's premise, questions they consider unnecessary, stops they work around, manual corrections, and elapsed time. Preserve abandoned work.
5. Have a person attempt the agreed interface task. Record their actions and result on the exact candidate they used. Ask the builder what they would use JudgmentKit for next. A stated intention to return remains an interview answer until return use is observed.
6. Decide whether the complete builder loop is ready for the pilot. Write the next product decision and the evidence behind it. A successful encounter is a learning result, not an efficacy claim.

Record these fields in a local encounter note: participant pseudonyms; task and source identities; original brief; comparison differences; configured tools and limits; observed event references; candidate identities; builder effort; end-user actions and results; known confounds; next decision. Leave unknown fields blank.
