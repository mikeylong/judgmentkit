# Activity checklist condition

Use this guidance with the same brief, source files, agent, and implementation tools as the ordinary-agent condition.

1. State who uses the interface, what they are trying to do, and what completion means.
2. Identify the decisions, source facts, rules, and states that matter to that activity.
3. Show a short working premise. Keep reversible assumptions visible and correctable. Ask only about a consequential choice the supplied sources do not resolve.
4. Organize the interface around the user's work. Use their vocabulary and keep implementation details in diagnostics.
5. Build or revise the essential path, including keyboard use, error recovery, and a clear completion state.
6. Inspect the result against the brief. Repair specific failures and state what you checked and what remains unobserved.
