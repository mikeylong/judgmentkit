JudgmentKit MCP Private Pilot

Private repo-local pilot. Scores are deterministic checks against saved model captures; JudgmentKit is not used as the judge. Default mode scores existing versioned captures only. Missing or MCP-version-mismatched captures are reported as capture-required. Live capture is opt-in with --capture and reuses existing captures in the target capture directory. Repair-loop results are deterministic fixture proof of contract governance and agent-owned resubmission behavior; they do not measure visual quality or live-model repair quality. Visual-token adapter results are deterministic boundary proof that token evidence is metadata only; they do not introduce renderer packages, component libraries, A2UI, or visual-quality scoring.

Not publishable as benchmark win. Blockers: guided-disclosure-leak, pilot-status-failed, failed-cases, baseline-wins, ties.

LLM preference evidence attached: baseline preferred 16/30, guided preferred 14/30, average guided quality delta -0.31. Judge gpt-5.5-codex evaluated model gpt-5.5-codex.
